# v0.6 本地封面与个人模板

## 功能

- 模板广场的工具栏和独立卡片提供「新建模板」入口；访客点击后引导登录。
- 填写名称（80 字以内）、介绍（400 字以内）、生成提示词（1000 字以内），选择单图或双图创作，上传 JPEG/PNG 封面（5 MiB 以内）。上传验证与原素材入口一致。
- 创建后自动切换到「我的模板」，点击卡片进入制作页，可查看自己的提示词。照片在制作时另外上传，封面不作为模型参考图。
- 自建模板仅本人可见，随账户持久化。服务端统一检查列表、详情、封面和任务创建权限，不以隐藏按钮代替权限校验。
- 百炼生成读取数据库里的模板提示词，追加竖版 3:4、保留主体、不加文字标识的公共约束。无密钥仍返回程序绘制的模拟图，模拟图不执行提示词效果。
- 六张系统封面均已下载到 backend/src/main/resources/template-covers；图片原始许可、署名和来源保留，页面不会向 Commons 发起图片请求。详见封面图片来源.md。
- 本轮范围为新建与使用；编辑、删除、共享模板尚未实现。

## 数据升级

新增 V5__personal_templates.sql，扩展 template 的归属账户、封面素材、提示词、创建时间，并补充系统模板提示词。保留 V1–V4 和已有任务、账户、媒体数据。模板当前不可修改，因此排队任务使用的模板配置不会被编辑改变。

## 验证方式

Docker 构建执行 ESLint、TypeScript、Vitest、Next.js production build、Maven verify。

在独立 creative-studio-accounts 栈验证，显式清空 DASHSCOPE_API_KEY，使用独立数据库、媒体卷和 127.0.0.1:3101：

```sh
docker compose -p creative-studio-accounts -f compose.yaml -f tests/accounts.compose.yaml up -d --no-build --wait
docker compose -p creative-studio-accounts -f compose.yaml -f tests/accounts.compose.yaml --profile test run --rm verify node /tests/templates.mjs
docker compose -p creative-studio-accounts -f compose.yaml -f tests/accounts.compose.yaml --profile test run --rm verify
docker compose -p creative-studio-accounts -f compose.yaml -f tests/accounts.compose.yaml --profile test run --rm verify node /tests/accounts.mjs
docker compose -p creative-studio-accounts -f compose.yaml -f tests/accounts.compose.yaml --profile test run --rm verify node /tests/deletion.mjs
```

templates.mjs 覆盖六张 JPEG 与署名、访客创建限制、参数校验、外部 Origin 拒绝、他人封面拒绝、列表/详情/封面/制作隔离、双图数量校验、模拟制作成功、退出隐藏和重新登录恢复。

ImageGeneratorTest 使用模拟 HTTP 响应验证自建提示词及两张图片进入百炼请求。本轮未执行付费模型生成，实际模型效果不属于本轮验收结论；既有百炼对接保持原有策略。
