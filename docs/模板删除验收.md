# v0.6.1 自建模板删除

## 使用

登录 → 模板广场 → 我的模板 → 卡片下方「删除模板」→ 确认。

确认框说明删除影响，可取消。请求期间禁用按钮避免重复提交，失败保留弹窗和错误提示。若另一页面已删除同一个模板，则清理当前页面的过期卡片。删除最后一个模板后保留「我的模板」分类和新建入口。

## 数据与权限

- V6 迁移仅增加 template.deleted_at，保留旧迁移和数据。
- 删除接口 POST /api/templates/{id}/delete 要求注册账户、同源请求、本人归属；系统模板和他人模板不可删除。
- 采用逻辑删除，模板列表、详情和封面隐藏，新任务返回 404。界面暂不提供恢复功能。
- 模板配置、封面素材、已有制作记录和图片文件保留；后台已受理的任务仍可读取模板配置完成生成。
- 删除和任务受理在同一账户锁下串行化。创建任务取得锁后重新检查模板，防止在初始校验后模板被删除仍受理新任务。

## 自动验证

Docker build 执行前端 Lint、TypeScript、Vitest、生产构建和 Maven verify。

- DeleteTemplateDialog 测试：取消不发送请求、请求中防重、错误留在弹窗、重试成功、跨标签页重复删除处理。
- TaskService 测试：初次校验到事务提交之间删除模板，拒绝插入并不派发任务。
- tests/templates.mjs 在无密钥隔离环境验证：本人删除、访客/他人/系统模板/跨站请求拒绝、重复删除、列表/详情/封面隐藏、阻止新制作、旧作品/历史/素材保留、正在制作的任务继续成功。

本轮使用模拟模型执行删除相关集成验收，不调用付费百炼接口。主服务继续保留既有百炼配置。

## 结果（2026-10-30）

前端 23 项、后端 20 项单元测试通过；templates.mjs（含删除场景）及 api-smoke.mjs 集成检查通过。浏览器确认卡片删除入口、确认弹窗和取消保留模板。主服务升级至 V6 后健康检查通过，百炼模式与既有数据保留。
